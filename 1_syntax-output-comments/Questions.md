Topic 1: Syntax, Output & Comments
Exercise 1:
Print your name, age, and favorite city using three separate print statements. Add a comment above each line explaining what that line does.
Exercise 2:
Write a print statement that outputs a sentence containing a quote inside it (e.g., She said, "Python is fun!"). Write this same output three different ways:
•	Using double quotes
•	Using single quotes
•	Using escape characters (\" or \')
All three should produce the exact same output.
Exercise 3:
Write a small piece of code that intentionally contains a syntax error (e.g., a missing bracket, quote, or colon). Show the broken version, then fix it and show the corrected version. Include a comment explaining what caused the error.
