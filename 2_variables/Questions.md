# Topic 2: Variables

## Exercise 1:
Create 5 variables storing your personal details (name, age, city, favorite color, student status). Print each one using the variables (not hardcoded values).

## Exercise 2:
Use multiple assignment to assign 3 favorite subjects to 3 variables in a single line (e.g., a, b, c = "Math", "Physics", "Chemistry"), then print them.

Bonus: Assign the same value to 3 different variables in a single line (e.g., x = y = z = 100) and print them.

## Exercise 3:
Write 3 valid and 3 invalid variable names. Actually run the invalid ones in your code to see the real error Python gives (don't just comment them out — let them execute so the error shows). Then comment out or remove them, and add a comment explaining why each was invalid.
