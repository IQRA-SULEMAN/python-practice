# Topic 5: Strings

## Exercise 1:
Create a string variable with your full name. Print:

The string in uppercase
The string in lowercase
The length of the string using len()

## Exercise 2:
Using string slicing, extract and print:

The first 3 characters of your name
The last 3 characters of your name
Everything except the first character

## Exercise 3:
Take a sentence (e.g., "Python is fun to learn") and:

Check if the word "fun" exists in it using the in keyword
Replace "fun" with "powerful" using .replace()
Split the sentence into a list of words using .split()

Print the result of each step.
