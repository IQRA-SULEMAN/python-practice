# Topic 6: Booleans & Operators

## Exercise 1:
Create two variables with number values (e.g., a = 10, b = 20). Use comparison operators (==, !=, >, <, >=, <=) to compare them, and print the result of each comparison (each will return True or False).

## Exercise 2:
Create two boolean variables (e.g., is_student = True, has_laptop = False). Use logical operators (and, or, not) to combine them in 3 different expressions, and print the result of each.

## Exercise 3:
Create two number variables. Use arithmetic operators (+, -, *, /, //, %, **) to perform all 7 operations between them, and print each result with a short comment explaining what that operator does (e.g., // = floor division, % = remainder/modulus).
